# Gallery assets

The 12 initial entries are replaceable previews: eleven supplied school screenshot stills (113205 through 113637), followed by the existing campus exterior. The UI screenshot 113831 is excluded. No dates or children names have been added.

To add a photo, place a full WebP (up to 1600px) and a 400 ? 300 thumbnail here, then add one photo({...}) entry in src/data/gallery.js with its native dimensions, descriptive alt text, category, caption and optional date. Set placeholder: false for final approved photographs.
