# Golden nuts at navigation board rope holes

All twelve navigation-board rope holes receive a polished gold hex nut with an integrated raised washer and transparent center. The existing rope is drawn over the fitting and terminates in the open center. The image and cavity use the existing measured hole positions, so active labels cannot move the fittings. Central house hardware and the mobile drawer are retained.

Final built-in imagegen asset: `public/assets/nav/board-rope-hex-nut.webp`, 256 × 256 transparent WebP quality 0.97, downsampled from a 1254 × 1254 generated source for small UI rendering. Original board assets are unchanged.
