# Reference squirrel entry and peek

Six-second repeating sequence on the existing transparent squirrel canvas: sit, run, hop to the porch, enter head-first with rump and tail following, pause fully inside, peek through the circular opening, emerge, hop down and return to the starting branch position. Existing treehouse, circular opening, branch, rainbow, ropes and navigation assets are unchanged.

New character-only poses generated with the built-in imagegen tool are normalized into four 256 × 256 cells in `public/images/navigation/squirrel-entry-poses.webp`. Cells provide approach, rear-three-quarter entry, rump/tail and front peek. The existing gait sheet provides running and hopping. Both views use their measured native art coordinates. Portal masks apply only to the squirrel; the peek is restricted to the actual circle and never paints a new rim or opening. Reduced motion hides the animation, and page visibility pauses its timeline. Existing navigation and mascot controls remain available.

Validation: `node scripts/verify-squirrel-entry.mjs` checks mobile/desktop bark contact, all sequence phases, tail-last visibility, complete hiding inside, peek pixels constrained to the real opening, reduced motion and viewport overflow.
