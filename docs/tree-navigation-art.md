# Tree navigation artwork and verification

The change is limited to the header. The existing six routes, HTML link labels,
logo, wooden boards, original monkey, and squirrel sprite/animation are reused.

## Assets

- `public/images/navigation/branch-house-textured.png`: new 2172 × 724 transparent
  PNG, generated by the built-in image tool from `branch-house-original.png`.
  The original file is retained. The birdhouse design and scene composition were
  preserved while the bark was made thicker and more textured.
- `squirrel-gait-v2.webp`: reused without modification.
- `monkey-handle-grip.png`: 1536 x 1024 transparent edit of the original
  `monkey-featured.webp`, preserving its face, fur, belly and curled tail. Hands,
  contact shadows, bar and mounting straps are a coherent illustrated cutout.
  Replaces the separate `MonkeyHandle.jsx`, now removed; the button is still HTML.
- `branch-house-compact.png`: 1536 x 1024 transparent mobile companion art,
  keeping the birdhouse and foliage inside the frame instead of cropping them.
- `rope-fibers.png`: 1024 x 1536 transparent hemp texture. Its central strip is
  sampled at consistent proportions inside measured SVG rope paths, replacing
  the smooth gradient/diagonal-stripe texture. No blur or sharpening filters.
- `NavigationRopes.jsx`: measured bark-top/bark-bottom loops, twisted fibers,
  underside hitches and board fixings. Two ropes per visible board, including
  the central logo. Rear loops, front ropes and board knots use separate layers.

The desktop branch retains its intrinsic 3:1 aspect ratio in a 1060px-wide scene.
The header is now 446px high (previously about 570px at 1440px and 616px at 2560px).
At 1100px and below, a native 3:2 companion scene fits without horizontal cropping.
Its bark and door have their own traced geometry, including squirrel entry masking.
All text and links remain live HTML, with an accessible narrow-screen menu.

Root causes: the previous uncapped art/layout grew with viewport width; its mobile
minimum width cropped foliage; a separate handle could not correct unsuitable hand
poses; smooth procedural rope stripes did not match the richer bark. The new art
and rendering address these causes rather than adding filters or arbitrary offsets.
