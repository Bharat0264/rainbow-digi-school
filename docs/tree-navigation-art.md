# Tree navigation artwork and verification

The change is limited to the header. The existing six routes, HTML link labels,
logo, wooden boards, original monkey, and squirrel sprite/animation are reused.

## Assets

- `public/images/navigation/branch-house-textured.png`: new 2172 × 724 transparent
  PNG, generated by the built-in image tool from `branch-house-original.png`.
  The original file is retained. The birdhouse design and scene composition were
  preserved while the bark was made thicker and more textured.
- `monkey-featured.webp` and `squirrel-gait-v2.webp`: reused without modification.
- `MonkeyHandle.jsx`: scalable wood-grain handle with two supports and contact
  shadows, positioned behind the existing mascot's raised fists.
- `NavigationRopes.jsx`: measured bark-top/bark-bottom loops, twisted fibers,
  underside hitches and board fixings. Two ropes per visible board, including
  the central logo. Rear loops, front ropes and board knots use separate layers.

The branch uses its intrinsic 3:1 aspect ratio. On small screens, the canopy is
cropped horizontally instead of squeezed. The desktop scene has more vertical
room for the thicker canopy and monkey. All text and links remain live HTML.

## Image tool prompts

Initial edit (input: original branch PNG):

> Use case: precise-object-edit. Asset type: transparent tree branch + central birdhouse layer for an existing children's school navigation UI. Edit the supplied transparent branch art. Keep the same panoramic 3:1 canvas proportions, same central wooden birdhouse design and round entrance, same branch centerline gentle U curve and object positions. Improve only the branch, foliage, and cutout quality: thicker natural reddish-brown bark with sculpted irregular ridges, visible distinct wood grain, fine cracks, knots, small naturally connected twigs and warm realistic lighting. Premium polished 3D cartoon game-asset illustration, richly textured but clearly illustrated, not a photograph. Lush varied fresh green leaves, actual translucent alpha edges, clean smooth contours, no yellow/green matte fringe. Keep the wooden birdhouse with grey-brown shingle roof centered in upper middle. Branch spans fully left to right; bark upper surface around 36-40% of canvas height at center and around 28% near edges; bark lower edge around 52-55% in center, 43% at edges; leaves extend above and below but the entire bottom 38% of canvas stays EMPTY TRANSPARENT to allow our real HTML signs below. The branch should read thick and solid, with highlights above and dark recesses on its underside. Very crisp full-width art. NO ropes, NO hanging signs or boards, NO monkey, NO squirrel, NO text, NO letters, NO logo. Preserve real transparent background. This is a separate layered background asset, not a finished website screenshot.

Final edge refinement (input: generated branch PNG):

> Precise image edit: Keep the entire illustration EXACTLY as it is: identical bark and foliage details, central birdhouse, positions, proportions and 2172x724 canvas. Only clean the transparency edges. Remove ALL bright yellow and neon-green matte halos/stray pixels outlining the silhouette, particularly between leaf clusters and above the bark. The outermost visible pixels must be the actual natural green of each leaf or actual brown bark, transitioning smoothly to true zero-alpha empty transparency. Do not add outlines, stroke, glow or shadows outside the objects. Output a clean professionally alpha-matted transparent PNG preserving every illustrated object. Keep the large transparent bottom area. No new objects, no text.
